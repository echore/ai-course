What · Instruction file

CLAUDE.md and AGENTS.md serve the same purpose: instructions the agent reads at the start of every session.

01   Plain text

A file written in everyday language.

02   Read automatically

Put it in the right place, and the agent loads it when a session starts.

03   Guidance, not a lock

It guides what the agent does. Hard limits come from permissions, in Module 3.

Claude Code uses CLAUDE.md. Codex uses AGENTS.md.

How · Where it lives

There are two levels: global and project.

Global

Your habits and preferences. Applies to every project.

Project

This project’s goal and rules. Applies only to this project.

Keep the two consistent. Tools handle conflicts differently, so don’t write rules that contradict each other.

How · Keep it short

Short, specific, and easy to check.

The file is loaded every session. The longer it gets, the more space it takes and the less reliably the agent follows it.

VagueSpecific
Global
“Understand what I want.”
→
“Before a multi-step task, confirm in one sentence the goal, what’s out of scope, and what ‘done’ looks like.”
Project
“Make the report clear.”
→
“Open with three bullet points on what changed since last week. Put the full numbers in a table below.”
Project
“Keep it short.”
→
“Keep the summary under 200 words, because the team reads it on their phones.”

Global example adapted from the instructor’s own instruction file.

Takeaway

✓
Write it down

If you’ve had to explain it twice, put it in the instruction file.

✓
Guidance, not a lock

The agent usually follows it, but not always.

✓
Be specific

If you can’t tell whether it followed a rule, the rule is too vague.
