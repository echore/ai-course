What · Three questions

Managing context comes down to three questions.

Context is everything the agent can see right now. It rereads all of it at every step, so the more there is, the easier it is to miss something.

01   What goes in?

Give it only what this task needs.

02   What must stay?

Put what matters in a file, outside the conversation.

03   When do you clear it?

Reset on purpose.

Most of the time you just keep working. These three habits keep a long job on track.

01 · What goes in

Give the agent only what this task needs.

Say you are working with an agent on a weekly sales report. Whatever it opens goes into the context and is reread at every step.

Too much
Just enough
What you ask for
“Look through all my sales files.”
→
“Open last week’s sales sheet and read the Totals tab.”
How you split the work
One conversation for the sales report, a job ad, and a trip plan.
→
One conversation for each job.

The less it has to reread, the less likely it is to miss something.

02 · What must stay

Put what matters in a file.

The Boston store closed, so you tell the agent to leave it out of this report. If that rule lives only in the conversation, it can get lost.

Instruction file

Rules that hold every week, such as the report format. The agent reads it on its own at the start of every conversation.

Handoff note

This week’s rules and progress, such as “leave out the Boston store”. The agent reads it only when you ask.

You say“Write a handoff note for this report: the goal, my rules, what is done, what is left, and where the files are. Save it as handoff.md.”

A note the agent never reads does nothing. Next time, start with: “Read handoff.md first.”

The instruction file is usually called CLAUDE.md or AGENTS.md.

03 · When to clear

Reset only when the job changes or the conversation gets long.

Context has a limit. When it is nearly full, Claude Code and Codex replace the conversation with a short summary, without asking you what to keep.

When
Do this

→
Start freshOpen a new, empty conversation. Your instruction file loads again.
Same job, long conversation
→
CompactThe agent replaces the conversation with a short summary, and you keep going. Then ask it to repeat your rules.
Same job, but the conversation is a mess, or you will continue another day
→
Hand offAsk for a handoff note, start fresh, then say “Read handoff.md first.”

In Claude Code and Codex, /clear starts a new conversation and /compact makes the summary.
