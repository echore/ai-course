Why · The problem

The longer the conversation, the easier it is to miss something.

Remember the Boston store from the last module? In the morning, you told the agent to leave it out. By the end of the day, it was back in the draft.

Watch for these signs

It forgets a rule you gave it.

It repeats work it already did.

It answers a different question.

These signs are your cue for step 3.

Step 1 · Every time

Step 1: One job, one conversation, and only what that job needs.

What the agent opens tends to stay in the context and gets reread at every step.

Too much
Just enough
What you ask for
“Look through all my sales files.”
→
“Open last week’s sales sheet and read the Totals tab.”
How you split the work
One conversation for the sales report, a client email, and a trip plan.
→
One conversation for each job.

New job? Start a new conversation.

Step 2 · Every time

Step 2: If a rule needs to stick, put it in a file.

Ask yourself: is this rule for every week, or just for this job?

Every week → Instruction file

“Reports are one page.”Read at the start of each conversation. See Module 2a.

Just this job → handoff.md

“Leave out the Boston store this week.”Usually read only when you ask.

You say“Add this to handoff.md: leave out the Boston store this week.”

The instruction file is usually called CLAUDE.md or AGENTS.md.

Step 3 · When it slips

Step 3: When it slips, hand off and start fresh.

Do this when you see one of the signs, or when you’re stopping for the day.

1Update handoff.md
→
2Start a new conversation
→
3“Read handoff.md first.”
→
4It repeats your rules
You say“Update handoff.md: the goal, my rules, what’s done, what’s left, and where the files are.”

A shortcut: /compact has the agent summarize the conversation so you can keep going. It’s quicker, but you don’t choose what it keeps. Claude Code and Codex also compact on their own when the context gets close to full.
