Why

A long conversation makes the agent less reliable.

Context is everything the agent can see right now: its instructions, its tools, the files it has read, and your conversation.

01   It rereads everything

At every step, the agent reads the whole context again.

→
02   The context keeps growing

Your messages, and whatever the agent opens or looks up, are added as you work.

→
03   Details get lost

The more there is to read, the easier it is to miss something you said earlier.

The context grows as you work. You choose when to reset it.

How · Four choices

When a piece of work is done, you have four choices.

Say you are working with an agent on a weekly sales report. A piece of work is done when the numbers are checked, or when the draft is written.

Keep going

Change nothing.

Use it when

The next piece builds on this one, and the conversation is still short.

The numbers are checked. Next: write the summary.

Start fresh

Start a new, empty conversation.

Use it when

The next job has nothing to do with this one.

The report is sent. Next: plan a team offsite.

Compact

The agent replaces the conversation with a short summary, then carries on.

Use it when

You still need what happened, but the conversation is long.

A long afternoon of fixes is done. Next: one last read-through.

Hand off

The agent writes the important parts into a file. A new conversation reads that file first.

Use it when

The work continues somewhere else: tomorrow, in another tool, or with a teammate.

A teammate takes over to finish this week’s report.

In Claude Code and Codex, /clear starts a new conversation and /compact compacts. Your instruction file, the standing rules the agent reads at every start, still loads.

How · Say what to keep

A summary is a retelling. Say what to keep, then check.

A retelling always drops details. Two habits protect the important ones.

01   Before: say what must stay
/compact Keep the corrected numbers and my rule: leave out the Boston store.
02   After: ask it to repeat your rules
“What are my rules for this report?”

If one is missing, say it again.

Claude Code and Codex also compact on their own when the context is nearly full. They can’t know what you plan to do next.

The command in step 1 is from Claude Code. Step 2 works in any tool.

How · The handoff note

A good handoff note covers four things.

Ask for it in plain words: “Write a handoff note so a new conversation can finish this report. Save it as handoff.md.”

01   The goal

What we are making, and who it is for.

02   The rules

What must stay true. “Leave out the Boston store.”

03   Done and left

What is finished, and the next steps in order.

04   Where things are

Which files, which sheet.

Read the note before you leave, and ask the agent to add anything missing. In the new conversation, have it read the note first.
