Why · The problem

“Done” is where checking starts.

The Monday sales report again. In the brief, you agreed that returns reduce sales. The agent says: “Done. All regions checked.”

The agent sounded sure, and it was still wrong. A confident “done” is not evidence.

One reason agents sound sure: many tests used to score AI models give points for a right guess and nothing for “I don’t know.”

Step 1 · Every time

Step 1: Check it against the source, not the agent’s word.

What must be trueCompare withResult
One pageThe report itselfPASS
Four regions, both weeksThe report’s rows and datesPASS
East sales = orders − returnsBoth source sheets: $45,900, not $48,200FAIL
You say“Compare the report with the source sheets. Show each comparison. Mark each item pass, fail, or couldn’t check, and say why.”

Can’t check it yourself, or it really matters? Open a fresh conversation, give it the brief, the result, and the sources, and ask it to check. Look at its evidence: it can be wrong too.

Module 5 · Preview

Step 2 · Every time

Step 2: Point at it. Say what you expected, what you got, and why.

Expected

East sales of $45,900: orders minus returns.

Got

$48,200 in the report.

Evidence

The East rows in both source sheets.

You say“Expected East sales of $45,900, orders minus returns. Got $48,200. Here are the source rows. Fix it and show me the check again.”

A one-off slip, like a typo in a title? You’re done here.

Module 5 · Preview

Step 3 · If it could be anywhere else

Step 3: If it could be anywhere else, fix the cause.

You ask“Where did this first go wrong, and what else uses that step?”

Fix where it started, not just where you saw it.

Don’t loosen a check just to get a pass.

Module 5 · Preview

Step 4 · If it could come back

Step 4: If it could come back, add a check.

Ask yourself

Will I run this task again?

Have I seen this mistake before?

Either answer yes? Write it down.
Add to CHECKLIST.md“Every region’s sales equal orders minus returns, in both weeks.”
At each delivery, you say“Read CHECKLIST.md, run every check, and show me the results.”

Test the new check once: run it on the old wrong report. It should fail.

You can also add a rule to your instruction file so the agent gets it right the first time. The checklist catches it if it doesn’t.
