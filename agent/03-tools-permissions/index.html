Tools · What it can’t reach

Out of the box, it can’t open your other apps.

In Module 1, tools are how an agent takes action. It comes with a few.

It comes with
Reading and editing files in your folder
Running commands on your computer
Searching the web
It can’t open
Google Sheets
Google Drive
Slack
Notion

They live in other apps, behind your login.

So for the Monday report, you copy the numbers in by hand, every week.

Tools · From copying to connecting

Connect the apps your weekly report needs.

Google Sheets

It reads last week’s sales numbers.

Google Drive

It finds last week’s report and follows the same format.

Google Docs

It writes this week’s draft for you to review.

You review the report instead of moving the data.

What it can do depends on the connection and the access you give it.

Tools · MCP

MCP is the standard way to make these connections.

Before

Every AI app needed its own custom link to every other app.

With MCP

An app builds one MCP connection, and every AI app that supports MCP can use it.

Think of it as USB-C for AI: one port that works everywhere.

Products call these connectors, apps, or plugins. You’ll add one in the Live session.

Permissions · Modes

A permission mode decides what the agent can do without asking you.

Your instruction file can’t stop an action. A permission can.

Asks you moreWorks more on its own
Plan

It only reads and writes a plan. Nothing changes yet.

Manual

It asks before every edit or command.

Accept edits

It edits files on its own, and asks before most commands.

Auto

It works on its own, and a safety check reviews each action.

Mode names from Claude Code. Other tools have similar modes.

Permissions · How to use them

A simple routine for any task.

1
Start in Plan.

Read its plan and fix anything wrong before it touches your files.

2
Save a version with Git.

Git keeps saved versions of your project, so you can go back if something breaks. You can ask the agent to do it for you.

3
Switch to Auto and let it work.

Switch to Manual when a step feels risky or new.

Never use a mode that skips every check on your own computer.

Takeaway

✓
Connect when you copy

If you keep copying things in from another app, consider connecting it.

✓
Allow only what the task needs

A report draft doesn’t need permission to email your whole team.

✓
Plan, save, then let go

Approve its plan and save a version with Git before it works on its own.
