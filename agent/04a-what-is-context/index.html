What · Context

Context is everything the agent can see right now.

In Module 1, the agent loop “keeps context”. This is what that word means.

Contextwhat the agent can see right now
Instruction file

The rules you wrote for it.

Module 2
Connected tools

The list of apps it can reach.

Module 3
Files and results

What it has opened or fetched. The spreadsheet. Last week’s report.

Your conversation

Everything you and the agent have said in this session.

If something is not in the context, the agent can’t see it until it goes and gets it.

Your agent tool, such as Claude Code or Codex, also adds its own built-in instructions. You can’t edit those.

Why · The trouble

In a long conversation, the agent starts to forget what you told it.

Back to the Monday report.

Morning

You say:

“This week, put the totals at the top and leave out the test store.”
→
All afternoon

You fix numbers and reword the summary. It opens file after file.

→
End of day

The new draft has the totals at the bottom.

The test store is back.

Nothing broke. The conversation just got long.

Why · It rereads everything

At every step, it rereads the whole context from the top.

Remember the loop from Module 1. Each turn of the loop starts by reading everything again.

01   Nothing stays in its head

Between steps it keeps nothing. It reads the whole context again each time.

02   Everything is added

Each message, each file it opens, each result that comes back goes onto the pile.

So the context keeps growing as you work.

When the context gets close to full, the tool shortens it for you. More on that in the next video.

Why · Attention

The more it has to read, the less attention each part gets.

Your morning request is still there. It is now one line in a very long page.

Common signs
It forgets a rule you gave it.
It repeats work it already did.
It answers a different question.

There is no clear moment when it breaks. Treat these signs as a hint to check.

A longer context also uses up your plan or budget faster.

Sources: Anthropic, “Effective context engineering for AI agents” (2025); Chroma, “Context Rot” (2025)
