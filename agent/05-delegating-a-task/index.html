Why · The problem

A finished report may still be the wrong report.

Every Monday, your sales lead reads a report on last week’s sales to decide which regions need follow-up. You ask an agent: “Make the weekly sales report.”

The request left these choices open, so the agent filled them in with its own guesses.

Step 1 · Every time

Step 1: Say what you want and what done looks like.

Fill in the blanks“Make ___ for ___. Use ___. Done means: ___.”
MakeA one-page sales report
ForThe sales lead, to decide which regions need follow-up
UseThe two weekly sales sheets, and last Monday’s report for the layout
Done meansOne row per region. Last week next to the week before. Same layout as last Monday’s.

Can’t fill in “Done means”? The task probably isn’t ready to hand off. Work that out first; the agent can help. The next module checks the result against this line.

Step 2 · Every time

Step 2: Tell it to ask, not guess.

It might ask

“Which dates count as a week?”

“Should returns reduce sales?”

“Is West’s blank a zero, or missing data?”

Before it starts, you say“Before you start, ask me about anything unclear that could change the result.”
And add“If a new choice like this comes up later, stop and ask me.”

Answer its questions, and add the answers to your request.

Module 4 · Preview

Step 3 · If it’s big

Step 3: If it’s big, plan first and start small.

A simple test: could you check the whole result in a few minutes? If not, treat it as big.

  1. 1
    A short plan you read first
  2. 2
    One region from start to finish
  3. 3
    Check it records and totals
  4. 4
    The rest after it passes
You say“Show me a short plan first. Then do one region from start to finish, and show me what you checked.”

In Claude Code, Plan mode lets the agent read your files and plan without editing them.

Module 4 · Preview

Step 4 · If it could do damage

Step 4: If it could do damage, work on a copy and keep it asking.

Could it change, delete, or send something that’s hard to undo? If so, do both.

Say it: in your request

“Work on a copy. Don’t edit the original files. Don’t send anything.”This guides the agent. It usually follows it, but the tool doesn’t enforce it.

Set it: in permissions

Keep Manual mode on, so the agent asks you before most edits and commands.Claude Code enforces this, not the agent. See Module 2b.

Permissions lower the risk. Still read what the agent asks before you approve it.
