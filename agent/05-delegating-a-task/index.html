Why · The cause

Missing context can lead the agent to make the wrong assumptions.

The agent works from the instructions and information available to it. It cannot reliably know the requirements you left unstated.

Your request
“Make the weekly sales report.”

Which regions should it include?

Which weeks should it compare?

Should sales include or exclude returns?

Which layout should it follow?

The agent may ask, or it may choose an answer and continue. Make important requirements explicit, and ask it to state assumptions that could change the result.

Clear instructions help, but the agent can still make mistakes.

Rule 1 · Choose the task

Rule 1: Choose work you can describe, check, and recover from.

To delegate is to give an agent responsibility for carrying out a task.

Describe it.

State the result you want.“A one-page sales report by region.”

Check it.

Know how you will judge the result.“Each region’s sales must match the source records.”

Recover from it.

Limit the damage if something goes wrong.“Create a separate draft and keep the source files unchanged.”

Taste and judgment: ask for options and review them.

Actions that are hard to undo: review and approve the exact action before it happens.

Drafting the report and emailing it are separate actions.

Rule 2 · Write the brief

Rule 2: Write a brief with four parts.

A brief is a written description of the task. It states what you want and what counts as done.

PartWhat it definesFor the Monday report
GoalWho needs the result and why.Help the sales lead decide which regions need follow-up.
MaterialsThe inputs and references.Sales sheets for both weeks. Last Monday’s report as the layout reference.
LimitsWhat the agent may do and must leave alone.Create a separate draft. No forecasts, source edits, or sending.
DoneWhat must be true when the task is finished.One page. One row per region. Correct dates and amounts. Show both weeks and the change in sales amount. Label missing data.

Decide what counts as done before work starts.

Tool permissions can block actions. Set them to match the limits in your brief.

Rule 3 · Clarify and plan

Rule 3: Clarify important choices, then review the plan.

For an unclear task, ask the agent to read the materials and identify choices that could change the result.

“Which dates count as a week?”

“Should returns reduce the sales amount?”

“Is West’s missing entry missing data, or a confirmed zero?”

You say“Before making changes, ask me about choices that affect the result. State your proposed assumptions and any missing information. Then draft the brief and a short plan for me to review.”

New questions may appear during execution. Agree when the agent should pause and ask you.

Read one region’s records. Calculate its sales and the change. Put the result in the agreed layout.

After it passes

Add the other regions. Check every region and the full-report totals. Finish the one-page report.

Ask the agent to show which records it used and what it checked. Verify the result before expanding.

A layout with invented numbers does not test the calculation. If you notice a wrong assumption, correct it at the next safe stopping point.
