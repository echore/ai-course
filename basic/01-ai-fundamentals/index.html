ARTIFICIAL INTELLIGENCESystems performing tasks associated with intelligence

AI BASIC · WEEK 01

HOW

Training is not the same as using a model

A resume uploaded as context does not automatically retrain the model.

Training

Model parameters are adjusted using data and optimization.

Inference

A trained model processes an input and generates an output.

In our app

Resume + job description → inference → feedback; no custom model training needed.

MECHANICS

Models process tokens, not whole pages

Words, word fragments, punctuation and other symbols may be tokens.

Illustrative text segments — real tokenization depends on the model.

Context capacity

Both resume and job description occupy context.

API usage

Input and output tokens often affect cost and latency.

AI BASIC · WEEK 01

MECHANICS

Same resume. Different job descriptions.

The information supplied with a request changes what the model can consider.

Without job context

“Improve this resume.” → General advice.

With job context

“Compare this resume with a marketing analyst role.” → More relevant analysis.

Critical distinction

A context window is not necessarily permanent memory or model training.

AI BASIC · WEEK 01

APPLY

What should our resume analyzer do?

Use AI for interpretation; use deterministic software for exact checks.

Extract

Identify requirements and experiences from text.

Compare

Find requirements with evidence in the resume—and those not demonstrated.

Suggest

Recommend truthful improvements without creating fictional qualifications.

AI BASIC · WEEK 01

RISK

Fluent feedback can still be wrong

What if the model invents a qualification?

FICTIONAL RESUME

“Coordinated 12 campus events and analyzed attendee survey feedback.”

UNSUPPORTED AI OUTPUT

“Strong Python and SQL engineering background.”

PAUSE & PREDICT: Where is the evidence for that claim?

AI BASIC · WEEK 01

SAFETY

Design for evidence and user control

The app should never encourage students to fabricate qualifications.

Grounded feedback

Quote or point to resume evidence for each strength.

Privacy by design

Use fictional materials for class; never publish real resumes or API keys.

Human review

Treat AI suggestions as drafts, not objective hiring predictions.

AI BASIC · WEEK 01

DECIDE

Not every step needs a language model

Choose the simplest reliable mechanism for each task.

Use regular code

Count words, check required fields, detect exact keywords.

Use an LLM

Interpret varied descriptions and suggest truthful phrasing.

Use both

Validate inputs with code, ask the model for interpretation, check its output.
