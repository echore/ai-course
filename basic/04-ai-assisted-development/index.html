AI FOUNDATIONS · WEEK 04 · 06/12

REVIEW

A diff tells you what changed.

Read the change, not just the AI-generated explanation.

git diff · core.py
def classify_requirement(item, resume):
- return "not evidenced"
+ return "unsupported"
+ API_KEY = "sk-demo-hardcoded"
REVIEW LIKE A BUILDER
01 · What behavior changed?

“Unsupported” overstates what missing text proves.

02 · What new risk appeared?

Never put credentials into tracked source code—even as a demonstration pattern.

03 · Can I explain every line?

If not, ask for clarification before accepting it.

AI FOUNDATIONS · WEEK 04 · 08/12

TEST

A test is an executable expectation.

Arrange → Act → Assert. You define what success means.

test_core.py
def test_python_is_supported():
    resume = "Built Python scripts"
    job = "Python required"

    result = analyze(resume, job)

    assert "Python" in result["supported"]
ARRANGE
Make the input

Fictional resume and job description

ACT
Call the function

Get the result without a user interface

ASSERT
Check the promise

Did Python land in the correct list?
