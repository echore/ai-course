AI FOUNDATIONS · WEEK 02

MINDSET

A prompt is an instruction, not a magic spell

Good prompting reduces ambiguity. It does not guarantee correctness.

VAGUE REQUEST
“Review this resume.”

Review for what? Against which requirements?

TASK BRIEF
“Compare the resume with this job description.”

Specify the evidence, rules, and output.

Prompt engineering = designing, testing, and refining model inputs.

BEFORE → AFTER

Add criteria. Remove the guesswork.

The improved prompt makes the desired behavior observable.

BETTER PROMPT

Compare the resume and job description.

Identify supported strengths and requirements not evidenced.

Give three truthful suggestions.

Quote resume evidence for every strength.

Never invent skills or achievements.

More precise instructions make mistakes easier to spot—not impossible.

AI FOUNDATIONS · WEEK 02

STRUCTURE

Make the output predictable with JSON

JSON organizes model output into named fields and values.

FREE-FORM FEEDBACK

“Maya seems like a fit in some areas, but she could improve SQL...”

Harder to parse consistently

STRUCTURED FEEDBACK
{
  "requirement": "SQL",
  "status": "not_evidenced",
  "evidence": null
}
Correctly formatted JSON is not automatically factually correct.

AI FOUNDATIONS · WEEK 02

CHECK 03

Evidence before advice

Ground candidate claims in exact source text.

SUGGESTION A
“Highlight Excel survey analysis.”

Resume contains: “Analyzed attendee surveys using Excel.”

SUGGESTION B
“Claim advanced SQL experience.”

No SQL evidence appears in Maya's resume.

PAUSE & DECIDE · Which suggestion can we support?
A is supported; B is not. “Not evidenced” is not “does not know.”
